推广渠道

这里列出《你的作品》要推送到的所有渠道。内置 13 个平台已预置，也可以添加自定义 webhook / 第三方 API 作为新渠道。
💡
本地优先 + BYOK · 不存你的账号密码
Rokit 不要求、不存储你在各平台的账号密码。大多数内置平台通过内嵌「发布浏览器」登录并填写发布页，登录态由 Chromium 加密保存到 %APPDATA%/Rokit/Partitions/pub/，仅存本机，不上传；微信公众号另支持使用本机加密保存的 AppID / AppSecret 调用官方接口创建草稿。想推到钉钉 / 飞书 / Discord 等自定义服务？点 + 新增渠道 选「自定义渠道」填一个 Webhook URL 即可。查看 FAQ

渠道说明

两种渠道类型：
  • 内置平台：大多数平台使用内嵌浏览器填表；微信公众号使用官方 API 创建草稿，需要配置 AppID、AppSecret 和封面素材 ID，草稿仍需在公众号后台检查并发布。
  • 自定义渠道：填入 API 地址或 Webhook URL（如企业微信 / 钉钉 / Discord / 飞书机器人 / 自建服务），Rokit 会以 POST JSON 方式把标题与正文推给你。

关于 BYOK · 3 个常见疑问

  • Q：为什么不让我填账号密码？
    A：Rokit 不调用平台 API，也不存账号。你只需在 Rokit 内嵌的「发布浏览器」里手动登录一次即可。
  • Q：登录态存在哪？
    A：%APPDATA%/Rokit/Partitions/pub/（与 SQLite 同目录分区，由 Chromium 加密）。主进程不会读取 / 转发。
  • Q：换电脑怎么办？
    A：Rokit 不做云同步，换电脑 = 在新机器上重新登录每个平台。配合浏览器自带密码同步可一键登录。
更多答疑（企业微信 / 多电脑同步 / 平台大改版应对等）见 推广渠道 FAQ 或 docs/channels-faq.md。

推广渠道 FAQ · 关于 BYOK

点击 查看完整文档（含 8 条答疑） · 完整 FAQ 同步存于 docs/channels-faq.md
Q1. 为什么推广渠道里没有「账号 / 密码」字段？
Rokit 不存你的平台账号密码。大多数内置平台通过内嵌浏览器登录；微信公众号可选用官方 API 创建草稿，AppID / AppSecret 由本机系统凭据管理器保护。
Q2. 登录态存在哪？怎么换电脑？
%APPDATA%/Rokit/Partitions/pub/（与 SQLite 同目录分区，Chromium 加密）。不做云同步——换电脑 = 在新 Rokit 上重新登录每个平台。配合浏览器自带密码管理器可一键登录。
Q3. 怎么彻底删除 Rokit 留下的登录信息？
删除整个 %APPDATA%/Rokit/ 目录即可。Windows 设置 → 应用 → Rokit → 卸载 也会一并清理。
Q4. 平台大改版导致自动发布失败怎么办？
短期用「复制 + 打开」手动发布；长期在 GitHub Issue 反馈，维护者会同步 publishers.js。MVP 1.5 会接入 L1 直发（本地 OAuth / 平台 API）作为兑底。
Q5. 自定义渠道的 Webhook / API 安全吗？
URL / Key 仅存本机 SQLite，POST JSON 推给你自己的服务。Rokit 不验证目标合法性——请确认你填的 URL 确实是你自己的服务（企业微信 / 钉钉 / 飞书 / Discord Webhook 等）。
